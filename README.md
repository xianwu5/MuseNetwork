# MuseNetwork

高级网络工程师学习文件夹，2026-11-04 建立，GitHub 持续更新：每学完一个知识点，笔记和实验配置都会同步到这里。

目标：半年内（到 2027 年 5 月左右）掌握企业网和园区网的搭建维护。
起点：数据中心网络运维，有网络基础；2026-11-04 进阶测评 8 题对 3 题。

## 文件夹结构

- `plan.md`：半年学习计划
- `notes/`：每学完一个知识点整理成一篇学习笔记
- `notes/index.md`：笔记目录，按学习顺序更新
- `notes/template.md`：笔记模板
- `labs/`：实验记录、拓扑和配置练习
- `quizzes/`：测评题目和复盘

## 约定

- 每次对话的学习内容同步更新到这里。
- 每学完一个知识点，就在 `notes/` 里新增一篇笔记，并在 `notes/index.md` 里登记。
- 笔记格式统一用 `notes/template.md`。
